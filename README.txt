SHOPEASE - VS CODE PROJECT

1. Extract the ShopEase folder.
2. Open Visual Studio Code.
3. Select File > Open Folder and choose the ShopEase folder.
4. Open index.html.
5. Right-click index.html and choose "Open with Live Server" (install the Live Server extension if needed).
   You can also open index.html directly in your browser, but Live Server is recommended.

PROJECT STRUCTURE

ShopEase/
  index.html             Home page
  products.html          Product catalogue
  cart.html              Shopping cart
  about.html             About page
  contact.html           Contact page
  review.html            Customer reviews
  login.html             Login page
  signup.html            Registration page
  shopkeeper.html        Seller dashboard
  css/                   Stylesheets
  js/                    JavaScript files

DEMO NOTES
- This is a front-end demonstration project. It does not use a real server, database, or payment gateway.
- Cart, demo account, seller products, and submitted reviews are stored in the browser's localStorage.
- Demo coupon code: EASE10.
- The login page checks accounts created through this browser's Sign Up page. Password storage is only for this local demo and is not suitable for a real website.
- Product photos on the supplied pages use online image URLs, so an internet connection is needed for those images and the Google Font.
